# Repositório de Estudos de Programação

Bem-vindo ao meu repositório de estudos de programação! Este espaço é dedicado ao meu aprendizado e à prática de diversas linguagens e tecnologias. Aqui você encontrará anotações, exercícios e pequenos projetos que desenvolvi ao longo da minha jornada como programador.

## 📚 Conteúdo

O repositório está organizado em pastas, cada uma focada em uma área de estudo específica:

### `/Programação`

Esta é a seção principal, contendo subdiretórios para diferentes linguagens de programação:

- **`Aula_C`**: Exercícios e exemplos básicos em linguagem C.
- **`Aula_PHP`**: Scripts e exercícios práticos com PHP.
- **`Aula_python`**: Exemplos de código e exercícios em Python.
- **`Java_WSL`**: Projetos e estudos em Java utilizando o WSL (Windows Subsystem for Linux).
- **`Aula_Javascript`**: Projetos e estudos com JavaScript.

## 🎯 Objetivo

O principal objetivo deste repositório é documentar meu progresso e servir como um portfólio pessoal de estudos. Sinta-se à vontade para explorar o conteúdo, usar os exemplos e aprender junto comigo.

## 🤝 Contribuições

Este é um projeto de aprendizado pessoal, mas sugestões e correções são sempre bem-vindas. Se encontrar algum erro ou tiver uma ideia para melhorar o código, sinta-se à vontade para abrir uma *issue* ou enviar um *pull request*.
